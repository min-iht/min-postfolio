# 스모크 테스트

완료 선언의 근거를 만드는 절차다. 통과/실패를 체크리스트로 보고하고, 시각 변경이면 스크린샷을 첨부한다.

## 준비

1. `preview_start`로 `portfolio` 서버 시작 (기본 8123, 점유 시 autoPort 배정 — 결과가 알려주는 포트 사용), `min.postfolio-ko.html` 열기.
2. **히어로 인트로를 보려면** javascript_tool로 `sessionStorage.clear()` 후 새로고침. (heroDone이 있으면 인트로를 건너뛰는 게 정상 — 버그 아님.)
3. 브라우저 패널 탭이 `document.visibilityState === "hidden"`이면 rAF가 멈춰 GSAP 애니메이션·스크린샷이 진행되지 않는다. 이때는 `sessionStorage.setItem('heroDone','1')` 후 새로고침(동기 복원 경로)으로 잠금 해제하고, 애니메이션 의존 검증은 "미확인"으로 보고한다.

## 데스크톱 (1280×800)

| # | 확인 | 통과 조건 |
|---|---|---|
| 1 | 히어로: 이름 입력 → Enter | 봉투 애니메이션 재생, 엽서에 입력한 이름 표시, 끝나면 스크롤 풀림 |
| 2 | 히어로: 새로고침 | 인트로 스킵, 바로 완료 상태, 스크롤 가능 |
| 3 | Works 스크롤 | 오른쪽 정보 카드가 포스터 섹션 따라 교체, 좌측 서브메뉴 active 이동 |
| 4 | 노트: Open the NOTE | 패널 슬라이드 인, 탭 클릭 시 해당 사진으로, 스와이프 동작, 뒤 페이지 스크롤 잠김 |
| 5 | 노트 닫기 3경로 | 클로즈 버튼 / ESC / 바깥 클릭 — 각각 닫히고 스크롤 복원 |
| 6 | Workshop | 카드 무한 드래그, VIEW DETAIL로 상세 열림·닫힘 |
| 7 | 팝업 (CONTACT / SUBSCRIBE / 미션) | 열림·닫힘, 팝업이 슬라이드 위에 떠 있을 때 ESC는 팝업만 닫음 |
| 8 | console | 에러 0 (`read_console_messages` onlyErrors) |
| 9 | 네트워크 | 404 리소스 없음 — 단, 알려진 5건(img/cv/skill_figma.png, img/info/*.png)은 기존 이슈로 제외 |

## 태블릿 (1024×768) / 모바일 (375×812)

`resize_window`로 각 폭에서:

| # | 확인 | 통과 조건 |
|---|---|---|
| 10 | 상단 바 | leftUI가 상단 고정 바로 변신, 콘텐츠와 겹침 없음 |
| 11 | 햄버거 | 열기/닫기/ESC/링크 클릭 시 닫힘, 열린 동안 뒤 스크롤 잠김 |
| 12 | 정보 카드 | ≤1024에서 `.info` 카드가 각 포스터 아래로 이동해 항상 보임 |
| 13 | 가로 스크롤 | 없음 (`document.documentElement.scrollWidth <= innerWidth`) |
| 14 | 폭 전환 | 1024↔1280을 넘나들어도 카드가 제자리로 복귀, 메뉴 닫힘 |
